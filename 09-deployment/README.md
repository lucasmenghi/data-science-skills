# 09-deployment — Disponibilização e operação

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [mlflow-registration](mlflow-registration/SKILL.md) | Preparar registro de artefatos no MLflow com linhagem, assinatura e evidências reproduzíveis. |
| [model-versioning](model-versioning/SKILL.md) | Versionar modelo, dados, features e política para reprodução e rollback coerentes. |
| [serving-readiness](serving-readiness/SKILL.md) | Avaliar prontidão de inferência batch ou online sob contrato, carga e falhas reais. |
| [deployment-checklist](deployment-checklist/SKILL.md) | Preparar plano de lançamento gradual e reversível com critérios, observabilidade e responsáveis. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
