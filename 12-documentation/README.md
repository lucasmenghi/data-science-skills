# 12-documentation — Documentação

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [model-card](model-card/SKILL.md) | Produzir model card rastreável com usos, avaliação, limitações e responsabilidades. |
| [technical-report](technical-report/SKILL.md) | Escrever relatório técnico reproduzível que conecta problema, método, resultados e limites. |
| [executive-summary](executive-summary/SKILL.md) | Produzir resumo executivo com decisão, impacto, evidência e solicitação concreta. |
| [readme-generator](readme-generator/SKILL.md) | Criar README que permite entender, instalar e reproduzir um projeto com comandos verificados. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
