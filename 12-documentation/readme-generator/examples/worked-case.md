# Caso trabalhado: readme-generator

Cenário sintético de decisão; não é resultado executado em dados reais.

## Situação e análise

Um repositório possui apenas biblioteca de instruções. O README deve explicar como invocá-las e validá-las, sem anunciar um serviço autônomo ou aplicação implantada.

## Recomendação explicada

Explicação de uso precisa corresponder ao estado real. Uma biblioteca pode estar completa no escopo sem ter integração validada em todos os ambientes.

## O que entregar

README navegável; quickstart; comandos verificados; pré-requisitos e limitações.

## Como verificar

Verificar links, nomes e consistência com código; preservar licença real sem atribuir licença ausente.

## Contraponto

Evitar roadmap descrito como funcionalidade. Se a premissa do caso mudar, reavaliar a decisão em vez de reutilizar a conclusão. Informar o que falta para passar de hipótese a evidência.
