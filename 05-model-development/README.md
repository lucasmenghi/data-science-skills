# 05-model-development — Desenvolvimento de modelos

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [algorithm-selection](algorithm-selection/SKILL.md) | Escolher famílias de modelos por tarefa, dados, restrições e protocolo de comparação. |
| [baseline-builder](baseline-builder/SKILL.md) | Construir referência simples e reproduzível para demonstrar o valor adicional de modelos. |
| [hyperparameter-planner](hyperparameter-planner/SKILL.md) | Planejar busca de hiperparâmetros com orçamento, espaço coerente e avaliação independente. |
| [imbalance-strategy](imbalance-strategy/SKILL.md) | Tratar desbalanceamento de classes de acordo com prevalência, decisão e custo dos erros. |
| [cross-validation-planner](cross-validation-planner/SKILL.md) | Desenhar validação cruzada que reproduza a generalização desejada e a dependência dos dados. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
