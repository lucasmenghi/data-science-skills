# 04-feature-engineering — Engenharia de features

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [feature-brainstorm](feature-brainstorm/SKILL.md) | Propor features por hipótese de mecanismo, disponibilidade e custo de manutenção. |
| [feature-selection](feature-selection/SKILL.md) | Selecionar features por utilidade fora da amostra, estabilidade e custo sem contaminar validação. |
| [categorical-encoding](categorical-encoding/SKILL.md) | Escolher codificação categórica compatível com semântica, cardinalidade, modelo e categorias futuras. |
| [temporal-features](temporal-features/SKILL.md) | Construir features temporais point-in-time com janelas, lags e disponibilidade reproduzíveis. |
| [aggregation-features](aggregation-features/SKILL.md) | Construir agregações em SQL/Python com denominadores, granularidade e cobertura explícitos. |
| [interaction-features](interaction-features/SKILL.md) | Projetar interações, razões e transformações com justificativa e controle de complexidade. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
