# 03-data-preparation — Preparação de dados

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [missing-value-strategy](missing-value-strategy/SKILL.md) | Escolher e validar tratamento de ausências considerando mecanismo, disponibilidade e efeito operacional. |
| [outlier-investigation](outlier-investigation/SKILL.md) | Investigar valores extremos antes de decidir corrigir, limitar, transformar ou preservar. |
| [leakage-check](leakage-check/SKILL.md) | Auditar vazamento temporal, de rótulo, de entidades e de seleção ao longo de um pipeline. |
| [temporal-validation](temporal-validation/SKILL.md) | Verificar consistência temporal e maturação de dados antes de estabelecer folds e avaliação futura. |
| [feature-ready-validation](feature-ready-validation/SKILL.md) | Verificar contrato de entrada de um modelo e equivalência entre treinamento e inferência. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
