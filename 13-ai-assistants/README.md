# 13-ai-assistants — Assistentes de trabalho e aprendizagem

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [ds-workbench](ds-workbench/SKILL.md) | Coordenar tarefas reais de Data Science do problema à operação, escolhendo skills e explicando decisões ao usuário. |
| [eda-assistant](eda-assistant/SKILL.md) | Conduzir descoberta e exploração de um dataset como fluxo integrado orientado a decisões. |
| [feature-engineering-assistant](feature-engineering-assistant/SKILL.md) | Coordenar construção e validação de um conjunto de features com contratos e disponibilidade temporal. |
| [ml-reviewer](ml-reviewer/SKILL.md) | Coordenar revisão independente de artefatos de ML/IA com achados rastreáveis e escopo explícito. |
| [business-translator](business-translator/SKILL.md) | Coordenar tradução de trabalho analítico para decisões executivas e operacionais com evidência preservada. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
