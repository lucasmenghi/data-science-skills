# 10-monitoring — Monitoramento

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [data-drift](data-drift/SKILL.md) | Detectar e investigar mudanças nas entradas e na cobertura sem presumir queda de qualidade. |
| [concept-drift](concept-drift/SKILL.md) | Investigar mudanças na relação entre entradas e resultado usando rótulos maduros e hipóteses alternativas. |
| [performance-monitoring](performance-monitoring/SKILL.md) | Definir monitoramento de qualidade, política e operação com coortes maduras e ações claras. |
| [retraining-advisor](retraining-advisor/SKILL.md) | Decidir entre manter, recalibrar, corrigir dados, retreinar ou substituir uma solução. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
