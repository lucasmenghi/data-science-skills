# 08-experimentation — Experimentação e causalidade

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [ab-test-design](ab-test-design/SKILL.md) | Desenhar experimento controlado com estimando, randomização, potência e plano de análise. |
| [uplift-analysis](uplift-analysis/SKILL.md) | Estimar heterogeneidade de efeito de tratamento e avaliar políticas de intervenção. |
| [causal-thinking](causal-thinking/SKILL.md) | Estruturar perguntas causais, DAGs e estratégias de identificação antes de estimar efeitos. |
| [experiment-review](experiment-review/SKILL.md) | Revisar resultados experimentais quanto à integridade do desenho, estimação e decisão. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
