# 02-data-discovery — Descoberta e diagnóstico de dados

Skills de trabalho com instruções, critérios de decisão e casos sintéticos. Cada skill pode ser usada isoladamente.

| Skill | Quando usar |
|---|---|
| [dataset-profiler](dataset-profiler/SKILL.md) | Caracterizar cobertura, distribuição e qualidade inicial de um dataset sem confundir amostra com população. |
| [schema-mapper](schema-mapper/SKILL.md) | Mapear semântica, tipos, chaves e contratos de dados entre fontes e camadas analíticas. |
| [granularity-check](granularity-check/SKILL.md) | Verificar unidade de análise, chaves e multiplicação de linhas antes de agregações e joins. |
| [data-quality-audit](data-quality-audit/SKILL.md) | Auditar regras de qualidade por impacto, distinguindo falha técnica, exceção legítima e ausência de cobertura. |
| [relationship-mapper](relationship-mapper/SKILL.md) | Investigar relações entre tabelas e entidades com cardinalidade, cobertura e consistência temporal. |
| [exploratory-analysis](exploratory-analysis/SKILL.md) | Conduzir análise exploratória orientada a perguntas com comparações válidas e achados acionáveis. |

Comece pelo [guia de trabalho](../QUICKSTART.md). Métodos e execução devem respeitar a disponibilidade real de dados e o objetivo do usuário. Não é necessário percorrer toda a categoria em cada tarefa.
