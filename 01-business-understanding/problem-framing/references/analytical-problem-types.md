# Analytical problem types

## Descriptive analysis
Use when the objective is to understand what happened or how a population behaves.

## Diagnostic analysis
Use when the objective is to investigate why an event or variation happened.

## Classification
Use when the output is a discrete category or event probability.

## Regression
Use when the output is a continuous numeric value.

## Ranking
Use when the objective is to prioritize entities under limited capacity.

## Clustering
Use when the objective is to discover groups without a predefined target.

## Time-series forecasting
Use when the objective is to estimate future values indexed by time.

## Causal inference
Use when the objective is to estimate the effect of an intervention.

## Optimization
Use when the objective is to choose the best action under constraints.
