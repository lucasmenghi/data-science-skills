# Temporal windows

## Observation window
Historical period used to create explanatory variables.

## Reference date
Point in time at which the prediction is considered to happen.

## Gap window
Optional safety interval between observation and performance windows.

## Performance window
Future period used to determine whether the target event occurred.

## Maturity
A sample is mature only when its full performance window is observable.

## Censoring
A sample is censored when the outcome cannot yet be reliably determined.
